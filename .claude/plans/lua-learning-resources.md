# Lua 学習教材まとめ

## 共通（バージョン非依存）

### 公式
- **Programming in Lua (PiL)**: https://www.lua.org/pil/ — 初版はオンライン無料公開。最もおすすめ（第4版は Lua 5.3 対応）

### チュートリアル・学習サイト
- **Learn Lua in Y Minutes**: https://learnxinyminutes.com/lua/ — 他言語経験者向け速習ガイド
- **Tutorialspoint Lua Tutorial**: https://www.tutorialspoint.com/lua/ — 基礎から体系的に学べる

### 日本語リソース
- Qiita・Zenn の Lua 解説記事

### 実践
- このプレイグラウンド環境で `scripts/` にコードを書いて実行するのが効果的
